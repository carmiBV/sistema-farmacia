# Procedimiento
1. Leer RNF operativos y arquitectura candidata.
2. Comparar despliegue simple, contenedores y servicios administrados.
3. Justificar explícitamente usar o no usar orquestadores.
4. Definir observabilidad, backup, recuperación y configuración.
5. Evitar complejidad no sustentada.
