# Procedimiento
1. Consolidar todos los análisis.
2. Explicar alternativas descartadas.
3. Crear matriz de decisión.
4. Seleccionar arquitectura condicionada a evidencia.
5. Documentar riesgos y pendientes.
6. Generar ADR.
7. Definir pruebas necesarias antes de implementación.
