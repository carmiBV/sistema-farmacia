# Procedimiento
1. Identificar activos y superficies de ataque.
2. Revisar autenticación y autorización.
3. Aplicar mínimo privilegio.
4. Revisar APIs, sesiones/tokens, secretos, auditoría, rate limiting y errores.
5. Identificar riesgos de terceros.
6. No generar código en esta fase.
